## 浏览器 Demo

```powershell
python -c "from run import app; app.run(host='127.0.0.1', port=5000, debug=False)"
```

打开 `http://127.0.0.1:5000/week4-demo`，依次点“正常请求”“重复请求”“篡改密文”“过期请求”。浏览器端生成 SM4 会话密钥，用服务端公钥做 SM2 C1C3C2 封装，正常请求由 Axios 拦截器发送；异常测试由 Fetch 发送；响应使用请求密钥派生的响应密钥解开。

## 注意

不要把 `.local/week4/sm2.json`、数据库或私钥加入提交。应用层隧道仍需 HTTPS，JWT/RBAC 和业务幂等仍然有效。captured-*.json 是真实本地 HTTP 请求/响应记录，不是 HAR 或 PCAP。可在浏览器 Network 中导出 HAR 作为抓包证据。
